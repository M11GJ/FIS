# 情報科学部の入学年度別カリキュラム

対応年度は2024・2025・2026年度です。入学年度はプロフィール属性として保持しますが、科目候補と卒業要件の判定には使用しません。

- 2024年度入学生用学生便覧（情報科学部）
- 令和7（2025）年度入学生学生便覧
- 令和8（2026）年度入学生学生便覧

3年度とも、卒業に必要な大分類の最低単位数は同じです。総計124単位、総合科目19単位、学科基礎科目とプログラム科目の合計80単位、実践英語4単位、選択プログラム22単位、演習8単位、他学科専門科目4単位を判定します。卒業論文の提出・合格は、履修科目データだけでは確認できないため注記として返します。

現在の科目候補は、全入学年度で共通の2026年度科目マスタ147件です。2026年度マスタで追加された次の科目も、2024・2025年度入学生が履修できます。

- オブジェクト指向プログラミング
- 応用数値解析
- データベース応用
- 金融工学

今後、大学が入学年度別の履修制限または卒業要件差を明示した場合だけ、公式資料を根拠として年度別ルールを追加します。

共有URLは147科目用の`v=2`形式を使用します。バージョン指定がない旧2024・2025年度リンクの24文字データは、当時の143科目順で復元して既存リンクの互換性を維持します。
