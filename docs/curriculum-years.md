# 情報科学部の入学年度別カリキュラム

対応年度は2024・2025・2026年度です。判定ルールと科目は、各年度の学生便覧を根拠に管理します。

- 2024年度入学生用学生便覧（情報科学部）
- 令和7（2025）年度入学生学生便覧
- 令和8（2026）年度入学生学生便覧

3年度とも、卒業に必要な大分類の最低単位数は同じです。総計124単位、総合科目19単位、学科基礎科目とプログラム科目の合計80単位、実践英語4単位、選択プログラム22単位、演習8単位、他学科専門科目4単位を判定します。卒業論文の提出・合格は、履修科目データだけでは確認できないため注記として返します。

2026年度から追加された情報科学部科目は、`entryYears: [2026]` を持つ年度限定科目として管理します。

- オブジェクト指向プログラミング
- 応用数値解析
- データベース応用
- 金融工学

年度指定がない既存科目は、対応する全年度で利用できるものとして扱います。便覧改訂時は、科目ごとの `entryYears` と `shared/curriculum.js` の要件を同時に更新してください。
